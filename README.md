# tatf
Repositorio para alojar y brindar recursos para el curso de Taller de Automatización Funcional.

## Pruebas de AdminCES

Los cuatro escenarios están integrados en `automation-framework`. Ver [preparación y descripción de los scripts](automation-framework/ADMINCES.md).

La base corresponde a la rama `generacion-scripts-1` del repositorio CES-Store/tatf. Las credenciales locales y las carpetas generadas por Maven quedan excluidas de Git.
